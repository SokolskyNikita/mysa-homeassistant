# Bluetooth protocol reference

The maintained BLE, Wi-Fi provisioning, SoftAP, and newer-model credential
transfer reference now lives in the standalone client repository:
[Mysa Bluetooth protocol](https://github.com/SokolskyNikita/mysa-client/blob/main/docs/reference/protocol/bluetooth.md).
The Wi-Fi setup implementation is maintained separately in
[mysa-wifi-setup](https://github.com/SokolskyNikita/mysa-wifi-setup).

## Scope and compatibility

See the maintained reference for model compatibility, hardware evidence, and
the distinction between Wi-Fi provisioning, account enrollment, and pairing.

## Credential transfer on newer models

See the maintained reference for the app-derived transfer format and its
hardware validation limits.

## Temporary Wi-Fi access point setup

See the maintained reference for the separate SoftAP path and the evidence
limits around its activation.
