# Cloud authentication

The Cognito and cloud-token protocol reference moved to the standalone
[`mysa-client` authentication guide](https://github.com/SokolskyNikita/mysa-client/blob/main/docs/reference/protocol/cloud-auth.md).
That guide covers SRP, refresh-token handling, headers, browser limits, and
the client's authentication errors.

For Home Assistant account setup, saved sign-in, password storage, and
reauthentication, see the [integration README](guides/usage.md#options-and-account-management)
and [integration architecture](architecture.md).
